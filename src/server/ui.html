🧩 Browser Extension & Integration

IDM-RS includes a native Chrome / Edge / Brave / Firefox integration extension located in:
C:\idm-rs\extension

How to install:
1. Open Chrome/Edge and go to chrome://extensions
2. Enable Developer Mode (toggle in top right).
3. Click "Load unpacked" and select folder C:\idm-rs\extension.
4. Any file you download or right-click in your browser is automatically accelerated by IDM-RS!
